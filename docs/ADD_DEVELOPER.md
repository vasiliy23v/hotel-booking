# Как добавить роль разработчика

## Роль разработчика

Роль разработчика (`'developer'`) имеет все права менеджера плюс возможность:
- Создавать других разработчиков
- Создавать менеджеров
- Полный доступ ко всем функциям системы

## Добавление первого разработчика

### Вариант 1: Через SQL (если есть доступ к базе данных)

1. Сначала убедитесь, что enum UserRole содержит значение 'developer':
```sql
ALTER TYPE "UserRole" ADD VALUE IF NOT EXISTS 'developer';
```

2. Затем обновите существующего пользователя (например, менеджера) на роль разработчика:
```sql
UPDATE users 
SET role = 'developer' 
WHERE id = 'user-id-здесь' OR email = 'email@example.com' OR phone = '+1234567890';
```

### Вариант 2: Через API (если уже есть менеджер)

Если у вас уже есть пользователь с ролью менеджера, вы можете обновить его роль через API:

```bash
# Обновить пользователя через API
curl -X PUT http://localhost:3000/api/users/[USER_ID] \
  -H "Content-Type: application/json" \
  -d '{
    "role": "developer"
  }'
```

Или через интерфейс управления пользователями в CMS (если уже есть разработчик).

### Вариант 3: Создать нового разработчика через API

```bash
# Создать нового разработчика
curl -X POST http://localhost:3000/api/users \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Имя Разработчика",
    "email": "developer@example.com",
    "phone": "+1234567890",
    "password": "secure_password",
    "role": "developer",
    "directCreate": true
  }'
```

**Важно:** Для использования `directCreate: true` нужно быть авторизованным как менеджер или разработчик.

## После добавления первого разработчика

После того, как первый разработчик создан, он может:
1. Войти в систему через `/cms/dashboard`
2. Перейти в раздел "Пользователи"
3. Создавать новых пользователей с ролью "Разработчик" через интерфейс

## Проверка роли

Роль разработчика отображается в интерфейсе как "Разработчик" и имеет полный доступ ко всем функциям системы.
