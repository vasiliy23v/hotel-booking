# 🚀 Быстрый старт: Система приглашений

## ✅ Что реализовано

1. ✅ Генерация уникальных токенов приглашений
2. ✅ Хэширование токенов для безопасности
3. ✅ API для создания и проверки приглашений
4. ✅ Страница регистрации `/invite/[token]`
5. ✅ Блокировка прямой регистрации
6. ✅ Проверка срока действия приглашений
7. ✅ Одноразовые токены
8. ✅ Привязка к email (опционально)

## 🎯 Как использовать

### Шаг 1: Создать приглашение

Используйте API или добавьте кнопку в админ-панель:

```typescript
import { api } from '@/lib/api';

// В компоненте или консоли
const invite = await api.createInvite(
  undefined, // email (необязательно)
  7, // срок действия в днях
  'admin-1' // ID администратора
);

console.log(invite.inviteUrl); // Отправьте эту ссылку пользователю
```

### Шаг 2: Пользователь регистрируется

Пользователь переходит по ссылке `/invite/[token]`:
- Токен автоматически проверяется
- Если валиден → показывается форма регистрации
- После регистрации токен помечается как использованный

### Шаг 3: Вход

Пользователь может войти на главной странице `/` используя созданные учетные данные.

## 📝 Примеры

### Создание приглашения для конкретного email

```typescript
const invite = await api.createInvite(
  'user@example.com', // email привязан
  14, // 14 дней
  'admin-1'
);
```

### Проверка токена

```typescript
const result = await api.verifyInviteToken('token-here');
if (result.valid) {
  console.log('Токен валиден!');
} else {
  console.log('Ошибка:', result.error);
}
```

## 🔒 Безопасность

- Токены хэшируются перед сохранением
- Используется `crypto.timingSafeEqual` для защиты от timing attacks
- Одноразовые токены (после использования нельзя использовать снова)
- Проверка срока действия
